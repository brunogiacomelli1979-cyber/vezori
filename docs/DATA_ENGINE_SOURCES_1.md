# Data Engine 1.0 — fontes, referências e direitos

Consulta em 07/11/2026. Sucesso HTTP ou licença de um parser não autoriza redistribuir os dados. Nenhuma flag de preços foi habilitada. A SEC foi expressamente adiada pelo proprietário nesta execução.

## Projetos open source examinados

Não houve cópia de código nem nova dependência de execução. O reaproveitamento é de padrões arquiteturais comparados com os contratos oficiais, em implementação própria stdlib. Não se alega instalação/execução dessas bibliotecas.

| Projeto e revisão | Licença / manutenção observada | Aproveitamento e compatibilidade |
|---|---|---|
| [PulseFlat](https://github.com/PulseDataLabs/PulseFlat), `2cf447a81f94959fe18a57f3ebf42c94b0bd5ee2` | README declara MIT, mas arquivo LICENSE não localizado; atualização 07/11/2026 | Referência de ciclos separados por fonte e relatórios. Sem copiar; repositório com grandes bases não foi clonado integralmente |
| [openmarket-br](https://github.com/Daniel-Castro754/openmarket-br), `7e7c6f785570d09292230c8f24f8a86163ce7e51` | MIT; atualização 21/09/2026 | Contratos de provider CVM, proveniência/ODbL e cache. FastAPI/PostgreSQL não foram adicionados ao Worker |
| [python-bcb](https://github.com/wilsonfreitas/python-bcb), `4fa647e3f26ef958a75a349adf460692b3d06954` | MIT; atualização 23/10/2026 | Referência de SGS com períodos explícitos, retries e separação de serviços. Para cinco séries, stdlib evita pandas/httpx e mantém implantação simples |
